# 💰 Banking System  

A **Java-based** banking system application that manages user accounts, transactions, and basic SQL operations.  

🚀 **Fast.** 🎯 **Reliable.** 🔒 **Secure.**  

---

### 🌐 Live Repository  
🔗 [Banking System on GitHub](https://github.com/RJDP05/Banking-System)  

---

## ✨ Features  
- 🏦 **Account Creation & Management** – Easily create and manage user accounts.  
- 🔑 **User Authentication** – Secure login and authentication system.  
- 🗃️ **SQL Integration** – Efficient data storage using MySQL.  
- 📦 **Modular Design** – Well-organized code with separate classes for each functionality.  

---

## 📁 Project Structure  

```
Banking-System-main/
│   ├── Banking System/
│       ├── .gitignore
│       ├── Banking System.iml
│       ├── .idea/
│       │   ├── .gitignore
│       │   ├── git_toolbox_blame.xml
│       │   ├── misc.xml
│       │   ├── modules.xml
│       │   └── libraries/
│       │       └── mysql_connector_j_9_2_0.xml
│       └── src/com/bankingsystem/
│           ├── AccountManager.java
│           ├── Accounts.java
│           ├── BankingApp.java
│           ├── BasicSQL.java
│           └── User.java
```

### 🔍 What's Inside?

- **src/com/bankingsystem/**: Main source code  
  - `AccountManager.java` – 🤖 Manages account operations.  
  - `Accounts.java` – 💳 Represents account details.  
  - `BankingApp.java` – 🚀 Application entry point.  
  - `BasicSQL.java` – 🗄️ Handles database operations.  
  - `User.java` – 👤 Manages user data and authentication.  

- **.idea/**: IntelliJ IDEA configuration files.  
- **Banking System.iml**: Project module file for IntelliJ.  

---

## ⚙️ Prerequisites  

- ☕ **Java Development Kit (JDK)** version 8 or higher.  
- 🗄️ **MySQL Connector** for Java (configured in `.idea/libraries/mysql_connector_j_9_2_0.xml`).  
- 💻 **IntelliJ IDEA** or any other Java IDE.  

---

## 🚀 Getting Started  

1. **Clone the repository:**  

   ```bash
   git clone https://github.com/RJDP05/Banking-System
   ```

2. **Open in IntelliJ IDEA.**  

3. **Configure MySQL settings** in `BasicSQL.java`.  

4. **Build and Run** the project from `BankingApp.java`.
